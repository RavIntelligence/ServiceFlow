# ServiceFlow – Render-ready MVP

This version adds a real Node.js backend and job database.

## Important
Twilio is optional at first. Without Twilio credentials, the app runs in demo mode and does not actually send SMS.

## Render
Build command:
npm install

Start command:
npm start

Environment variables:
TWILIO_ACCOUNT_SID
TWILIO_AUTH_TOKEN
TWILIO_PHONE_NUMBER
